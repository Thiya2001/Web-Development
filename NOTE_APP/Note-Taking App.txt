Note-Taking App with React, Node.js & MySQL:
---------------------------------------------

Login,  Registration, CRUD Operations, Producted Routes, Using React Router DOM, My SQL Database Connectivity, Axios using Client Server Request and Response.   

1) New Node JS app create => npm init -y
2) npm install express
3) npm install MySQL2 -> package used -> database connectivity
4) npm install bcryptjs -> use password encrypted
5) npm install jsonwebtoken -> login functionality
6) npm install cookie-parser -> login functionality
7) npm install cors -> to solve cors error
8) npm install dotenv -> file use credential store -> PORT = 5000
9) npm install multer -> package use server inside picture upload.
10) npm i nodemon -D -> install using developer dependency mainly use server automatically refresh.
11) package.json -> scripts inside "start": "nodemon index.js"

12) New server create on express package.
